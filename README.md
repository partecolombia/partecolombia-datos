# Parte Colombia — datos abiertos

Conteo independiente, con fuentes, de **neutralizaciones de integrantes de grupos armados por la
Fuerza Pública** en Colombia. Sitio: **https://partecolombia.com**

**Última actualización:** 2026-08-14 · **Total:** 563 neutralizados
(243 operaciones registradas).

## Contenido
| Archivo | Qué es |
|---|---|
| `data/meta.json` | Totales, conteos por fase, por grupo y por departamento |
| `data/serie_diaria.csv` / `.json` | Neutralizaciones por día (desglose) |
| `data/operaciones.csv` / `.json` | **Cada operación con su fuente** (URLs), fuerza, lugar, verificación |
| `data/objetivos.json` | Cabecillas seguidos (alias, grupo, estado, recompensa, fuentes) |
| `datos_completo.json` | Dataset completo tal cual lo publica el sitio |
| `METODOLOGIA.md` | Cómo contamos y qué cuenta |
